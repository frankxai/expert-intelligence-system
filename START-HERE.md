# Start Here

This is a 60-minute first cycle. It does not attempt to finish your whole system. It creates enough structure to make one useful decision.

## Before you begin

Create a private folder named `corpus/` outside any public GitHub repository. Add 3–5 representative items:

- one piece that best represents your thinking;
- one transcript, call note, or workshop;
- one framework, process, or teaching artifact;
- one example of work that helped someone;
- optionally, one item you now disagree with.

Do not upload material you do not own or have permission to process. Remove personal data, client details, and former-employer confidential information.

## Path A — no terminal

1. Download the repository as a ZIP.
2. Create a Project in ChatGPT or Claude.
3. Upload `AGENTS.md`, this file, the files under `expert/`, and your private corpus samples.
4. Paste:

   > Read `AGENTS.md` and `skills/expert-intake/SKILL.md`. Run the intake using only the files I supplied. Stop if the corpus is insufficient. Save the result in the format defined by the skill.

5. Review every quotation, source reference, and inference.

See the precise setup in [starter-packs/README.md](starter-packs/README.md).

## Path B — local folder or coding agent

Open this folder in Codex, Claude Code, or another file-aware agent and say:

> Read `AGENTS.md`, then run `skills/expert-intake/SKILL.md`. My private corpus is at `<path>`. Do not copy private source material into the repository.

The agent should write the first intake card under `work/intake/`.

## Your first cycle

### 1. Name the decision

Complete this sentence:

> I am building this system so I can ______ for ______ without ______.

A useful answer names a person, a result, and a constraint. “Make content with AI” is not specific enough.

### 2. Inventory the corpus

Record each source, ownership status, sensitivity, date range, and relevance. Do not deeply ingest yet.

### 3. Choose one route

- **Established Expert:** begin with `skills/discover-genius/SKILL.md`.
- **Emerging Founder:** begin with `skills/customer-discovery/SKILL.md`, then return to genius discovery after five conversations or five strong source artifacts.

### 4. Produce one map

The first useful result is not a chatbot. It is a map of what exists, what can be supported, what remains tacit, and what should happen next.

### 5. End with one commitment

Choose one artifact and a date. Examples:

- evidence map for the flagship framework by Friday;
- five customer interviews by 15 August;
- first research brief from the system by next Tuesday;
- one course module rebuilt with sources by the end of the month.

## First-cycle definition of done

- [ ] The corpus inventory names 3–5 representative sources.
- [ ] Ownership and sensitivity are clear.
- [ ] The route is explicit.
- [ ] The AI has not invented quotes or frameworks.
- [ ] One next artifact and date are named.
- [ ] Private source material remains private.
