# Expert Source of Truth

These files are the portable, human-readable core of the system. AI tools may propose changes, but the expert approves them.

| File | Question it answers |
| --- | --- |
| `GENIUS.md` | What patterns and cross-domain lens recur in the corpus? |
| `METHOD.md` | How does the expert move from problem to result? |
| `VOICE.md` | How does the expert make distinctions and communicate? |
| `AUDIENCE.md` | Whose progress is this system designed to support? |
| `EVIDENCE.md` | Which claims have which type of support? |
| `OFFERS.md` | What transformation is responsibly offered, and under what conditions? |
| `BOUNDARIES.md` | What must the system never claim, decide, publish, or expose? |

## Promotion rule

Draft findings belong under `work/maps/`. A finding moves here only when:

1. its source or reasoning is visible;
2. contradictions are represented;
3. privacy and ownership have been reviewed;
4. the human owner approves the change.

Keep empty sections visibly marked `unfilled`. Never invent content to make the system look complete.
