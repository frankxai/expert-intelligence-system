# ChatGPT Project Setup

1. Download this repository.
2. Create a new Project.
3. Upload:
   - `AGENTS.md`;
   - `START-HERE.md`;
   - `EXPERT-INTELLIGENCE-METHOD.md`;
   - `expert/*.md`;
   - the one `skills/*/SKILL.md` you are running.
4. Upload only the representative corpus files required for this cycle. Check your workspace's current data and retention settings first.
5. Add these Project instructions:

```text
Follow AGENTS.md as the operating contract.
Use only the named skill for the current task.
Never invent a quote, source, case, credential, or framework recurrence.
Label observations, interpretations, and evidence status separately.
Do not imply you accessed a file that is not present.
Return proposed source-of-truth changes for human approval.
End with one concrete artifact and date.
```

6. Begin:

```text
Run expert-intake. My intended progress is: <one sentence>.
My source files are: <names>.
The material is: <private/internal/public>.
```

Save approved outputs back into your local copy. Project chat history is not the source of truth.
