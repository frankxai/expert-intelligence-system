# Starter Packs

Choose the workspace you already use.

| Workspace | Guide | Best for |
| --- | --- | --- |
| ChatGPT Project | `chatgpt-project/INSTRUCTIONS.md` | No-terminal, conversational work |
| Claude Project or Cowork | `claude-project/INSTRUCTIONS.md` | Long documents and local collaborative work |
| Codex, Claude Code, or another coding agent | `coding-agent/INSTRUCTIONS.md` | File writes, validation, and Git history |

The system is the Markdown, not the vendor. Keep the reviewed files locally and export project outputs regularly.
