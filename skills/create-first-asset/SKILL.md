# Create First Asset

## Load

- `AGENTS.md`
- the relevant approved files in `expert/`;
- `agents/creator.md`;
- `agents/evidence-guardian.md` when factual claims matter.

## Process

1. Name the artifact, audience, decision, format, and deadline.
2. Select only the expert and evidence files relevant to it.
3. Draft an outline that maps sections to method, audience, and evidence.
4. Create the artifact.
5. Review:
   - method fidelity;
   - voice fidelity;
   - evidence and claim scope;
   - privacy and rights;
   - intended-user usefulness.
6. Return a `PASS`, `REVISE`, or `STOP` verdict.
7. After human review, record corrections in the learning ledger.

## Output

- `work/outputs/<artifact-slug>.md`
- `work/outputs/<artifact-slug>.review.md`
- `work/learning/<artifact-slug>-learning.md`

## Quality gate

- The artifact solves one named problem.
- Source-derived language is traceable.
- Important claims have evidence status.
- The output does not pretend to be the human.
- Publication or sending remains a human action.
