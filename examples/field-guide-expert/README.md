# Fictional Example — Mira Vale

Mira Vale is a fictional composite created to demonstrate the file shapes. She is not a client, and the outcomes below are not testimonials.

## Context

Mira is an experienced field educator who helps community program leaders turn informal local knowledge into practical learning guides. Her fictional corpus includes:

- three workshop transcripts;
- two facilitator guides;
- a project retrospective;
- a set of participant questions.

The example deliberately contains a practitioner-derived method and a hypothesis. It does not present invented research citations.

## Files

- `genius-map.md` — source-grounded candidate patterns;
- `method-map.md` — a small explicit method;
- `evidence-map.md` — honest claim classification;
- `first-asset.md` — one workshop outline produced from the system.
