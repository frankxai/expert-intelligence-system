# Method Map — Context-Preserving Field Guide

**Fictional example. Not externally validated.**

## Transformation

From a collection of local stories to a small field guide whose practices remain traceable to context.

## Stages

| Stage | Input | Judgment | Output | Failure mode |
| --- | --- | --- | --- | --- |
| Listen | Consented story | What decision is actually present? | Decision note | Imposing the facilitator's preferred lesson |
| Locate | Decision note | Which conditions shaped it? | Context card | Removing constraints to make it universal |
| Translate | Context card | What action can another person test? | Practice draft | Writing a slogan instead of an action |
| Challenge | Practice draft | Where would this fail? | Boundary note | Using only confirming examples |
| Teach | Practice + boundary | What does a learner need first? | Field-guide module | Assuming background knowledge |

## Decision rule

When a practice appears useful across three different contexts, promote it as a **candidate pattern**, not a universal rule. Ask the human facilitator when the source communities disagree about what the story means.
