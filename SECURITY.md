# Security and Privacy

## Private by default

Do not commit private corpus to this repository. `corpus/`, `private/`, and `work/private/` are ignored by Git, but an external encrypted or access-controlled folder is safer.

## Before adding a source

Confirm:

1. you own it or have permission to use it;
2. its intended purpose is clear;
3. personal and confidential data are minimized;
4. former-employer and client details are removed or explicitly authorized;
5. the selected AI provider and workspace settings are acceptable for that material.

## Reporting a vulnerability

Do not open a public issue containing sensitive data. Use GitHub's private security advisory flow for this repository.

## Consequential domains

This system can organize expert material. It does not replace qualified review. Medical, legal, financial, safety, scientific, and other high-stakes outputs require an accountable human expert and current authoritative sources.
