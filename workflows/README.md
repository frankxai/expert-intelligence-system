# End-to-End Workflows

## Established Expert

```text
Expert Intake
  → Reclaim Knowledge
  → Discover Genius
  → Distill Method
  → Build Evidence Map
  → human promotion into expert/
  → Create First Asset
  → Learning Ledger
```

Recommended first proof: rebuild one existing high-value artifact—such as a flagship lesson, research brief, or offer narrative—using the explicit system.

## Emerging Founder

```text
Expert Intake
  → Customer Discovery
  → Discover Genius from experience + conversations
  → Distill the smallest responsible method
  → Build Evidence Map
  → Design Expert Offer
  → Create First Asset or pilot
  → Learning Ledger
```

Recommended first proof: five customer conversations and one narrow pilot, not a large course.

## Institutional Pilot

Use a cohort of 5–12 experts. Each expert keeps a separate private corpus and source of truth.

1. common orientation and privacy rules;
2. individual intake and corpus mapping;
3. individual Genius and Method Maps;
4. evidence review by domain;
5. one artifact per expert;
6. cohort learning review using aggregated, non-confidential patterns.

Do not merge expert corpora into one shared model or repository by default.

## Weekly operating rhythm

- **Monday:** choose one decision or artifact.
- **Tuesday:** collect only the required sources.
- **Wednesday:** run the relevant map or creation skill.
- **Thursday:** evidence, voice, and boundary review.
- **Friday:** human decision, learning ledger, one next commitment.

The rhythm is a default, not a productivity doctrine. The artifact and gates matter more than the weekday.
