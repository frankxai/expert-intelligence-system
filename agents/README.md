# Agent Team

These role contracts are deliberately small. Add a role only when it changes the quality or safety of the work.

The [Expert Orchestrator](expert-orchestrator.md) selects one skill and admits only the specialists required for it. Every specialist cites inputs, distinguishes observation from inference, and writes to a named artifact.

An AI workspace may execute these roles sequentially. Parallel execution is optional and should never create competing edits to the same source-of-truth file.
