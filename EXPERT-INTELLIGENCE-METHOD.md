# The Expert Intelligence Method

The method turns a body of lived and professional work into a system that can support research, creation, teaching, customer learning, and business decisions without erasing the expert's voice or overstating the evidence.

## 1. Listen

**Question:** What is actually here?

Listen across source material and conversation before imposing a model. Record repeated distinctions, decisions, stories, language, tensions, and outcomes. A pattern is not a framework until it recurs across multiple sources.

**Outputs**

- intake card;
- corpus inventory;
- interview record;
- problem and intended-use statement.

**Gate:** no identity or genius claims without representative corpus.

## 2. Reclaim

**Question:** Where does the expert's knowledge live, and what can be used?

Map scattered material by function rather than by platform or employer. Mark ownership, sensitivity, age, and status. Separate transferable method from confidential examples.

**Outputs**

- source inventory;
- domain map;
- source-to-domain map;
- outdated and rights audit.

**Gate:** no ingestion of material without a clear right and purpose.

## 3. Distill

**Question:** What judgment, method, and language are genuinely distinctive?

Find repeated patterns, cross-domain synthesis, decision rules, failure modes, and boundary conditions. Preserve contradictions when they reveal development rather than smoothing them into a generic persona.

**Outputs**

- Genius Map;
- Method Map;
- Voice Protocol;
- Boundary Map.

**Gate:** frameworks require repeated observations and source references.

## 4. Encode

**Question:** How can another person or agent use this responsibly?

Write explicit files, schemas, skills, and agent contracts. Each role gets inputs, responsibilities, prohibited actions, outputs, and a writeback location.

**Outputs**

- expert source-of-truth files;
- evidence records;
- skills and agent roles;
- private/public boundary;
- review and approval rules.

**Gate:** consequential decisions and publication remain human-controlled.

## 5. Activate

**Question:** Can the system produce one useful piece of work?

Apply the system to a bounded outcome: research a claim, structure an offer, write a course module, draft a chapter, plan customer interviews, or prepare a workshop.

**Outputs**

- one shipped or review-ready artifact;
- evidence notes;
- decision log;
- evaluation against the expert files.

**Gate:** one useful result before expanding the agent team.

## 6. Compound

**Question:** What did the work teach the system?

Capture corrections, customer language, claim updates, new cases, and changed decisions. Promote learning into the source of truth only after human review.

**Outputs**

- learning ledger;
- revised expert files;
- new evidence records;
- next commitment.

**Gate:** working memory does not silently become canon.

## The artifact chain

```text
Corpus
  ↓
Corpus Inventory + Rights Audit
  ↓
Genius Map + Method Map + Voice Protocol
  ↓
Evidence Map + Audience Map + Boundaries
  ↓
Agent and Skill Contracts
  ↓
One Useful Artifact
  ↓
Learning Ledger → reviewed updates to the system
```

## Evidence classes

Every important claim uses one status:

| Status | Meaning |
| --- | --- |
| `supported` | Directly backed by a credible source or transparent dataset |
| `contested` | Credible sources or interpretations disagree |
| `practitioner-derived` | Repeated professional observation with documented cases, not general proof |
| `anecdotal` | A specific story or single observed case |
| `hypothesis` | A testable proposition not yet adequately supported |
| `metaphor` | A meaning-making or teaching device, not a factual claim |

The evidence class does not decide whether an idea is useful. It decides how honestly it may be presented.

## Quality test

An Expert Intelligence System is working when:

1. another person can trace a claim to its source or status;
2. the expert recognizes the voice without mistaking it for perfect imitation;
3. the system can explain when it should stop and ask;
4. an output reflects the method, not just the topic;
5. corrections improve the explicit files rather than disappearing into chat history;
6. the expert can move the system between tools without losing the core record.
